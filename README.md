# A4-2 - 글 속 정보와 기분 뽑아내기 (regex-sentiment)

> 🚧 **미착수** — 디렉터리·레포 준비만 완료

정규표현식으로 이메일·전화번호·날짜·금액·URL 을 추출해 정규화하고, 감성 사전에 부정어·강조어 규칙을 얹어
문장 감성을 판정한다. 정밀도·재현율·F1 로 규칙 기반 접근의 장점(정밀도·해석 가능성)과
한계(재현율·유지보수)를 측정하고, A4-1 의 통계 기반 접근과 비교한다.

- 과제 원문: 로컬 `../a4-2-regex-sentiment.md`
- AI 심화 학습 · 자연어 처리 · 70시간 · 필수 · 개인
- Python 3.10 이상 · `requirements.txt` 또는 `environment.yml` 필수
- 선행: A4-1 (원문이 "앞선 미션(NLP Mission 1)"을 전제, 같은 NSMC 데이터 재사용 가능)

## 설치 및 실행

```bash
uv venv --python 3.12 .venv && source .venv/bin/activate
uv pip install -r requirements.txt   # uv 가 없으면 python -m venv .venv 후 pip install -r requirements.txt
```

진입점은 착수 때 정한다 (원문 예시: `python main.py --text '테스트 문장'`).

> ⚠️ KoNLPy 는 Java(JDK)가 필요하다 — 현재 이 맥에는 Java 가 없다.

## 라이브러리 제약 (과제 §7)

| 구분 | 내용 |
|---|---|
| 정규표현식 | Python 내장 `re` |
| 형태소 분석 | KoNLPy(한국어) 또는 NLTK(영어) |
| 감성 사전 | 외부 사전(KNU 등)은 출처 명시 + 도메인 특화 단어 **30개 이상** 직접 추가 |
| 문서화 | 모든 정규식 패턴에 의도·매칭 범위 주석 |
